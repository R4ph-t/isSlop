Toolbar and popup mark from [Lucide](https://lucide.dev) `highlighter` (ISC License).

https://lucide.dev/icons/highlighter

`icon.svg` is that glyph on the same orange tile as the popup logo. The PNG canvas is transparent around the rounded tile (no square fill behind it). Chrome’s toolbar needs PNG, so `icon16.png` / `icon48.png` / `icon128.png` are rasters of the same file (drawn at native size — do not use `qlmanage`, which pads the glyph into a white square).
